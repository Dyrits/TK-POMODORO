# TK-POMODORO

A Pomodoro timer desktop app built with Python and Tkinter.

## About The Project

A graphical Pomodoro timer: 25-minute work sessions with 5-minute short breaks and a 60-minute long break, with a reset function and session checkmarks.

### Built With

- Python 3
- Tkinter

## Getting Started

### Prerequisites

- Python 3 (with Tkinter)

### Running

```sh
python main.py
```
